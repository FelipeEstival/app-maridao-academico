# Catálogos locais

Os catálogos fazem parte de `apps/mobile-sdk57/src/data/database.json` e são carregados diretamente pelo app, sem endpoint remoto.

- Serviços: 26 categorias e 156 especialidades.
- Localidades: 380 bairros, quadras e localidades do cadastro imobiliário municipal de Palmas.
- Coberturas: Toda Palmas, Centro/Plano Diretor, Taquaralto e Jardins Aureny.

A fonte original das localidades é o [Cadastro Imobiliário de Palmas](https://iptu.palmas.to.gov.br/pesquisar-cci/), coletado em 20/10/2026. A listagem não é um censo de bairros nem uma garantia de cobertura de áreas ainda não cadastradas. Os dados iniciais foram importados para o JSON do aplicativo; o funcionamento da aplicação não depende de consultar essa fonte durante a execução.
